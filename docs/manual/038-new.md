---
name: NEW
order: 38
token: auto
---


PURPOSE:

To reset BASIC memory and discard the
BASIC program or to perform a soft reset
the computer.

SYNTAX:
```text

NEW
NEW SYS
```

DESCRIPTION:

NEW is the CBM BASIC command for
removing the current BASIC program from
memory. MDBASIC has augmented it to
provide a system reset. If NEW is
followed by the SYS keyword then the
system performs a warm-start. This is
equivalent to using SYS64738 or pressing
the reset button on your computer. It is
provided convenience.

If a program has been NEW-ed or
warm-start performed you can restore the
previous BASIC program by using the OLD
command.

EXAMPLE:
```text

NEW :'THIS WILL REMOVE THE CURRENT BASIC
PROGRAM
NEWSYS :'THIS WILL PERFORM A WARM
RESTART OF THE COMPUTER
```
