PURPOSE:

To convert a 32-bit signed integer into
its hexadecimal string equivalent.

SYNTAX:
```text
H$ = HEX$(n)
```

DESCRIPTION:

HEX$ is a function that returns the
hexadecimal equivalent of the numeric
expression within parenthesis. The
Hexadecimal numbering system has a base
of
16, rather than base 10 of the Decimal
numbering system.

n is the 32-bit signed integer to
convert to a hexadecimal string of
characters. If n is a floating point
number then the fractional portion is
ignored. The maximum positive value is
2147483647 which equals $7FFFFFFF. The
most significant bit (31) is considered
the sign flag, therefore negative values
range from -1 ($FFFFFFFF) to -2147483647
($80000001).

EXAMPLE:
```text

'CONVERT DECIMAL CONSTANT TO HEX STRING,
PRINT RESULT
PRINT HEX$(49152)
C000

'CONVERT DECIMAL VARIABLE VALUE INTO HEX
STRING VARIABLE
V$ = HEX$(V)

'CONVERT BINARY CONSTANT TO HEX STRING,
PRINT RESULT
PRINT HEX$(%10010)
12

'CONVERT OCTAL CONSTANT TO HEX STRING,
PRINT RESULT
PRINT HEX$(@777)
1FF

'CONVERT A BINARY STRING TO DECIMAL THEN
HEX STRING THEN PRINT RESULT
B$="10010" : D=VALB(B$) : H$=HEX$(D) :
PRINT B$,D,H$
10010      18      12

'CONVERT AN OCTAL STRING TO HEX STRING
O$="172" : H$=HEX$(VALO(O$))
```
