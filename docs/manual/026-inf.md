name: INF()
order: 26
token: auto
---


PURPOSE:

To return various system information.

SYNTAX:
```text

I = INF(n)
```

DESCRIPTION:
n (0-70) selects the piece of system
information. Most information can be
read directly from memory registers
using PEEK statements. This function
helps reduce the use of PEEK statements
so that programmers do not have to
concern themselves with which memory
locations hold the data and how to parse
it. For example, INF 37 to 51 return
color values ensuring the range 0-15.
All sprite X- coordinates return the
9-bit value. INF 22 to 36 return a
16-bit value. Some values are only
applicable when a BASIC program is
running.
