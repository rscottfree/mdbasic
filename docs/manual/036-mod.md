PURPOSE:

To return the remainder of a division
operation.

SYNTAX:
```text

R = MOD(dividend, divisor)
```

DESCRIPTION:

MOD (modulo) is a function that returns
the remainder of a division operation.
This implementation uses truncated
division to determine the quotient. The
remainder has the same sign as the
dividend.

MOD is typically used with positive
integers however fractional values can
be used. The range of values for an
integer modulo operation of n is 0 to (n
− 1). Any integer n MOD 1 is always
equal to 0. nx mod n = 0 for all
positive integer values of x.

dividend (numerator) is the number to be
divided.

divisor (modulus) is the number used to
divide the numerator.

The following is the equivalent BASIC
expression:
R = X-TRIM(X/Y)*Y

It is common for BASIC to define
functions for a specific modulus
calculation. For example, to calculate X
MOD 12 the following function definition
can be used:
DEF FN M(X) = X-TRIM(X/12)*12
PRINT FN M(25)

The MOD function simplifies the
expression and is easier to understand
when reading program text.

EXAMPLE:
```text

10 R = MOD(25, 12) :'25/12 = QUOTIENT 2
REMAINDER 1, OR 2 AND 1/12
20 PRINT R
```
