name: CLR
order: 9
token: auto
---


PURPOSE:

To clear BASIC variables and stacks and
initialize the system.

SYNTAX:
```text

CLR
CLR SYS
```

DESCRIPTION:

CLR is the CBM BASIC statement for
clearing all BASIC variables and system
stack as well as restoring data reading
to the first line. MDBASIC has augmented
this statement to provide for a more
robust initialization of BASIC.

CLR performs the following
initializations:
1. Clear all variables and system stack
2. Close all open files and set default
devices & I/O channel (CLOSE FILES)
3. Restore data read to first line
(RESTORE)

CLRSYS includes the following additional
initializations:
4. Turn off error trapping (ERR OFF)
5. Turn off key trapping (KEY OFF)
6. Clear the keyboard buffer (KEY CLR)
7. Turn off all MDBASIC background
processes (PLAY OFF, PLAY SPRITE OFF)
8. Turn off all sprites (SPRITE OFF)
9. Enable Stop key (STOP KEY ON)
10. Enable STOP statements (STOP ON)
11. Clear last error info (ERR CLR)
12. Turn off sound by clearing all SID
registers (VOICE CLR)

CLRSYS allows a program to reset the
BASIC system state while it is running.
The program continues normally to the
next BASIC statement.

The stack is where all FOR/NEXT and
GOSUB information is stored. When it is
cleared the information is lost and thus
an error would occur when NEXT or RETURN
is encountered. In this case it would be
necessary to immediately GOTO a line not
incorporated with these statements.

EXAMPLE:
```text

CLR :'CLEAR BASIC VARS, CLOSE FILES,
RESTORE
CLRSYS    :'CLEAR/INIT THE BASIC SYSTEM
```
