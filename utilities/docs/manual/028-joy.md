PURPOSE:

To return the status of a joystick
plugged into Port 1 or 2.

SYNTAX:
```text

J = JOY(port)
```

DESCRIPTION:

port (1-2) selects the input port number
of the joystick.

J is the variable that will be assigned
to the current position of the stick.
The number returned will be from 0-10
with no button pressed, and 128-138 if
the button is pressed. To remove the
button state append the logical
operation AND
15. The number returned corresponds to a
direction in the table below.

| NUMBER | DIRECTION |
|--|--|
| 0 | no direction |
| 1 | up |
| 2 | down |
| 3 | --n/a-- |
| 4 | left |
| 5 | up & left |
| 6 | down & left |
| 7 | --n/a-- |
| 8 | right |
| 9 | up & right |
| 10 | down & right |

Refer to the example program at the end
of Appendix G.

EXAMPLE:
```text

'DISPLAY MSG IF JOYSTICK #1 IS PUSHED
DOWN (IGNORE BUTTON)
IF JOY(1) AND 15 = 2 THEN PRINT"DOWN"

'DISPLAY MSG IF JOYSTICK #2'S BUTTON IS
PRESSED
IF JOY(2)>10 THEN PRINT"FIRE"

'ACT ON ALL MOVEMENT-NOTE 3 & 7 ARE N/A
SO LINE 0 WILL SUFFICE
J% = JOY(1) AND 15 :'ALL EXCEPT FIRE
BUTTON
IF J% THEN ON J% GOSUB
100,110,0,130,140,150,0,170,180,190
```
